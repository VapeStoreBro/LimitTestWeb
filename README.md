# DORM MARKET

Адаптивный демонстрационный сайт мини-маркета для общежития.

## Возможности
- 16 товаров с фотографиями Unsplash
- Категории, фильтры и поиск
- Корзина с сохранением в localStorage
- Адаптивная вёрстка для мобильных устройств
- Демонстрационное оформление без платежей и передачи данных

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Файлы
- `index.html` — структура и контент
- `styles.css` — оформление и адаптивность
- `app.js` — каталог и интерактивность

Фотографии загружаются с images.unsplash.com и требуют доступа к интернету. Цены условные, реальные заказы не принимаются.
